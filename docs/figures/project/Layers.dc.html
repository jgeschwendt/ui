layer ①ui.tokensui.css · docs.cssEvery --ui-* custom property, declared once on bare :root; the dark blocks only reassign.docs.css adds --ui-measure and --ui-measure-wide here.Values only: nothing in this layer paints.
layer ②ui.baseui.cssThe reset, plus type and layout classes (.h1, .stack) that apply wherever used.The page furniture waits for .ui: ground, ink, font stack, box-sizing, the focus ring.One rule reaches every element unasked: [hidden].
layer ③ui.componentsui.cssEvery component class: .btn, .card, .panel, .pill and the rest; they style themselves with or without .ui.Section order is cascade order: a later section wins a same-specificity tie.
layer ④ui.docsdocs.cssThe shared docs shell: .docs-shell, .docs-section, figure.figure and the prose furniture.After the components, so the shell outranks [data-container].Additive only: every docs page links it latest.
no layer ⑤your pageits own stylesheet, unlayeredRules in no layer beat every layer before them, whatever the specificity.The layer a consumer overrides from. Override tokens, not rules: :root { --ui-accent: … } retints the whole library.A page's grids and lanes live here too.
the opt-in<body class="ui">Paints the ground ui-bg and ink ui-fg, sets the sans stack, box-sizing and the focus ring. On <body>, not <html>, so body's computed background is real.
the one rule that needs no class:where([hidden]:not([hidden="until-found"])) { display: none !important; }Components set display, and a class beats the UA's [hidden]. !important inverts the layer order, so this base rule outranks ui.components and el.hidden = true always hides.
